## 🚀 HOW TO USE

### Access
Navigate to `/homework/worksheet-builder` in the app

### Create a Worksheet
1. Click "Add Section" to choose exercise type
2. Fill in questions/items
3. Edit header (student name, subject, chapter)

### Export to PDF
1. Enable "Answer Key" if needed
2. Click "PDF" button
3. File downloads as `Chapter_YYYY-MM-DD.pdf`

### Save to Bank
1. Click "Save to Saved Sheets" button
2. Worksheet stored in localStorage
3. Access anytime from "Saved Sheets" drawer

### Backup/Restore
- **Export Backup:** Click export in Saved Sheets
- **Import Backup:** Click import in Saved Sheets
- **Export Single:** Export current as JSON
- **Import Single:** Load from JSON file
